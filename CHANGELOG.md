# Changelog

## v1.0.0 — 23 de octubre de 2026

Primera versión estable de **JokerTags Mobile** probada en Balatro Android con Lovely.

- Etiquetas compactas y dinámicas para los comodines.
- Indicadores de multiplicadores, fichas, dinero y contadores.
- Estados **ON/OFF** para efectos condicionales.
- Iconos de palos y etiquetas independientes para ediciones especiales.
- Código depurado sin cambios intencionados en la funcionalidad de la v0.20.

### Compatibilidad

- **Android + Lovely:** probado en una instalación móvil.
- **PC:** pendiente de validación práctica.

Descarga el ZIP instalable desde **Releases** cuando la v1.0.0 esté publicada. El código fuente y las notas de atribución están en este repositorio.
